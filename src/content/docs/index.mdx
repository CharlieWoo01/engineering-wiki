## How this wiki works

<CardGrid>
  <Card title="Documentation as code" icon="document">
    Every page is a Markdown or MDX file in Git. Changes are proposed, reviewed and validated in
    pull requests.
  </Card>
  <Card title="Validated automatically" icon="approve-check">
    CI checks formatting, frontmatter, internal links, accessibility and the production build before
    anything is published.
  </Card>
  <Card title="Fast to search" icon="magnifier">
    Press <kbd>/</kbd> or <kbd>Ctrl</kbd> + <kbd>K</kbd> to search every page. The index is built
    statically, so no backend is involved.
  </Card>
  <Card title="Templates included" icon="puzzle">
    Start new ADRs, runbooks, technical notes, guides, PoCs and evaluations from consistent
    templates.
  </Card>
</CardGrid>

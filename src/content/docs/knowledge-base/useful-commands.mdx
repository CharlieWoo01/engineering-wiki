## Git

```sh
# Undo the last commit but keep the changes staged
git reset --soft HEAD~1

# Interactively stage parts of a file
git add --patch

# Find the commit that introduced a bug
git bisect start && git bisect bad && git bisect good <known-good-sha>

# Show who last changed each line, ignoring whitespace changes
git blame -w path/to/file

# Work on two branches at once without stashing
git worktree add ../engineering-wiki-hotfix hotfix/broken-link
```

## pnpm

```sh
pnpm install --frozen-lockfile   # reproducible install, as in CI
pnpm outdated                     # list outdated dependencies
pnpm why <package>                # explain why a package is installed
pnpm audit --audit-level high     # check for known vulnerabilities
```

## Docker

```sh
# Remove stopped containers, unused networks and dangling images
docker system prune

# Open a shell in a running container
docker exec -it <container> sh

# Inspect the layers and size of an image
docker history --no-trunc <image>
```
